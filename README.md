
# TsukiToKokoro PWA

A personal aesthetic web planner and Instagram content dashboard inspired by anime and life realism.

## Features
- Drag & drop dashboard blocks
- Content calendar section
- Instagram stats preview
- Mobile friendly + PWA ready

## Setup

1. Upload all files to your GitHub repository (public).
2. Enable GitHub Pages from the repo settings.
3. Open the link to view your live PWA.
