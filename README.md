# TsukiToKokoroPWA

An aesthetic, anonymous Progressive Web App inspired by anime and deep reflections.  
Designed to help users reflect, write, and stay grounded in moments of emotion.

## Features
- Minimalist design
- Offline support (via Service Worker)
- Add to Home Screen (PWA)
- Fast, mobile-first UI
- Anime-themed aesthetics

## How to Use
1. Open the app in any modern browser.
2. You’ll get a prompt to install it (Add to Home Screen).
3. Start writing or reflecting anonymously.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- PWA manifest + service worker
